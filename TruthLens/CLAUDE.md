# TruthLens

> **Orientation.** Full documentation is in `README.md`; results and limitations are in
> `PHASE1_REPORT.md`. Three things that bite newcomers immediately:
>
> - `build_notebook.py` is the **source of truth** for the notebook. Edit it, never the
>   `.ipynb`, and regenerate before every run. Never regenerate while a run is in flight.
> - Python **3.11/3.12 only** — torch has no wheels for 3.13/3.14, and system python here
>   is 3.14.
> - `truthlens_outputs/demo_*` files come from an 18-post demonstration corpus and are
>   **not** research results. On AVeriTeC read macro-F1, not accuracy (61 % of the dev set
>   is one class). See `README.md` §3 for all five reporting traps.

### Rules — these always apply
- cite `github.com/MichSchli/AVeriTeC` for AVeriTeC downloads — the `huggingface.co/chenxwh/AVeriTeC` mirror is gated and returns 401 anonymously. <sub>(`learnings/averitec-provenance-and-retrospective-evidence.md`)</sub>
- in `bootstrap_ci`, draw one index vector per replicate and index BOTH arrays with it. Two independent draws destroys the pairing and reports the random-pairing rate. <sub>(`learnings/bootstrap-ci-must-resample-pairs-not-arrays.md`)</sub>
- strip the claim span from its own gold article before scoring claim-to-fact-check retrieval on FactDrill, and report the un-stripped number only as a labelled upper bound. <sub>(`learnings/factdrill-claim-is-copied-from-its-own-article.md`)</sub>
- report the evidence-corpus size and composition next to every retrieval metric — a Recall@k with no stated haystack is not a result. <sub>(`learnings/fever-corpus-protocol-inflates-recall.md`)</sub>
- run the NLI judge and sentence encoder on MPS (or CUDA) and pick the model tier from the device — never hardcode a small model to survive CPU. <sub>(`learnings/nli-throughput-mps-vs-cpu.md`)</sub>
- never write the notebook back on `KeyboardInterrupt`, and regenerate from `build_notebook.py` before every run. <sub>(`learnings/notebook-runner-clobber-hazard.md`)</sub>
- dense scoring is one matmul against a pre-normalised matrix plus `argpartition` — never a Python loop of `cosine()` calls, and never `list.index()` in a query path. <sub>(`learnings/retriever-must-be-vectorised-for-corpus-scale.md`)</sub>
